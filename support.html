Cattle & Herd Records

A chute-side record book for cow-calf operations. It works with no signal, and it will not let you ship an animal that is still inside a drug withdrawal window.

Getting your herd in

Settings → Import cattle from a spreadsheet. Export a CSV from whatever you keep now, paste or pick the file, and match the columns. Rows it cannot trust are counted and skipped rather than guessed at. Running the same file twice adds nothing.

Backing up

Settings → Back up everything writes one file holding the whole herd and its history. Records live only on this device, so take a backup before changing phones. Restore from the same screen, or from the welcome screen on a new device.

Withdrawal dates

The product library ships with example doses and withdrawal intervals. They are examples. Take the values from the product label, keep them current, and never treat this app as the only basis for a shipping decision.

Pounds or kilograms

Settings → Weights in. Everything is stored the same way underneath, so switching re-reads existing weights rather than changing them.

Autumn calving

Settings → Production year starts. A calf crop is a season, not a calendar year. An autumn-calving herd should start its year just before calving so one crop is counted once instead of split across two years.
